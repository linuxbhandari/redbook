Before we install Kube-OVN
===========================
I want to verify four things. These take less than a minute and can prevent hours of troubleshooting.

Run:

1. Pod CIDR
kubectl cluster-info dump | grep -m1 cluster-cidr

or

kubectl -n kube-system get cm kubeadm-config -o yaml | grep -A5 networking
2. CNI directory
ls -l /etc/cni/net.d

Expected:

total 0

or the directory may not exist.

There should not be any old Calico, Flannel, or Kube-OVN configuration files.

3. CNI binaries
ls /opt/cni/bin

It's fine if the binaries are present. What's important is that /etc/cni/net.d has no active configuration.

4. Node architecture
uname -m

I expect:

aarch64

because you're on Apple Silicon with UTM.



Install Kube-OVN
================

helm search repo kubeovn/kube-ovn --versions (optional)
helm repo add kubeovn https://kubeovn.github.io/kube-ovn
helm repo update
helm show values kubeovn/kube-ovn > values.yaml (optional for customization)

helm install kube-ovn kubeovn/kube-ovn -n kube-system --create-namespace --wait (For first time)
helm install kube-ovn kubeovn/kube-ovn -n kube-system --dry-run --debug
helm install kube-ovn kubeovn/kube-ovn -n kube-system --wait
helm install kube-ovn kubeovn/kube-ovn -n kube-system -f values.yaml --wait
