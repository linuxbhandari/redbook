	sudo /usr/sbin/cephadm shell --fsid 22c13af4-927b-11f1-b7ec-e2abf57fde49 -c /etc/ceph/ceph.conf -k /etc/ceph/ceph.client.admin.keyring

Or, if you are only running a single cluster on this host:

	sudo /usr/sbin/cephadm shell

Please consider enabling telemetry to help improve Ceph:

	ceph telemetry on

	https://docs.ceph.com/en/latest/mgr/telemetry/

Deleting cluster with fsid: f2dbeccc-9003-11f1-a154-e2abf57fde49


Verify the cluster is removed
Run:
	cephadm ls

It should return no daemons.
Also verify:
	podman ps -a

There should be no Ceph containers.
