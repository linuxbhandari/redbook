Install kube-ovn
================
helm repo add kubeovn https://kubeovn.github.io/kube-ovn/
helm repo update
helm repo list
helm search repo kubeovn


Install Kube-OVN
================
kubectl label node kube-master kube-ovn/role=master --overwrite
helm install kube-ovn kubeovn/kube-ovn --namespace kube-system --wait --version v1.16.2
helm show values kubeovn/kube-ovn > values.yaml
