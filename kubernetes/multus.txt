Multus Installation
-------------------

What is Multus?

Currently, every Pod gets one interface from Kube-OVN.

Pod
 │
eth0
 │
Kube-OVN
 │
10.16.x.x

With Multus:

                 Kubernetes
                      │
                  Multus CNI
                      │
        ┌─────────────┴─────────────┐
        │                           │
     Kube-OVN                  Macvlan
        │                           │
      eth0                       net1
   10.16.x.x                 192.168.x.x

Multus does not replace Kube-OVN. It adds extra interfaces.


Before installing Multus
------------------------
I want to explain one important concept.

CNI Chaining

Without Multus:

kubelet
   │
   ▼
Kube-OVN
   │
Pod

With Multus:

kubelet
   │
   ▼
Multus
   │
   ├── Kube-OVN (default network)
   │
   └── Macvlan (secondary network)

So Multus becomes the primary CNI configuration, but Kube-OVN remains the default network plugin.

Step 1 - Create a NetworkAttachmentDefinition

Save the following as macvlan-net.yaml:

apiVersion: k8s.cni.cncf.io/v1
kind: NetworkAttachmentDefinition
metadata:
  name: macvlan-net
spec:
  config: |
    {
      "cniVersion": "0.3.1",
      "type": "macvlan",
      "master": "enp0s1",
      "mode": "bridge",
      "ipam": {
        "type": "host-local",
        "subnet": "192.168.64.0/24",
        "rangeStart": "192.168.64.200",
        "rangeEnd": "192.168.64.220",
        "gateway": "192.168.64.1"
      }
    }

Apply it:

kubectl apply -f macvlan-net.yaml

Verify:

kubectl get network-attachment-definitions

Expected:

macvlan-net
